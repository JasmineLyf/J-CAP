# J-CAP 主实验复现包

本仓库仅包含冻结的 **J-CAP 主口径实验**。J-CAP 是原实验中 V13 JOINT-ANCHOR 的新名称，算法没有因更名而改变。输入为病区日级汇总数据，任务是在相同接收量及合法专科接收路径下，提前选择一个配置。

|方法|成功情景数|平均护理人力参照新增超额 H|平均床位新增超额 P|平均 J|
|---|---:|---:|---:|---:|
|J_CAP|59/348|2.521|0.540|6.769|

共87个评价日，每日 K=2、4、6、8，两个来源各接收 K/2。成功率为16.9540%。H/P/J 均先按每个日期×K情景计算，再等权平均；J=(10H+20P)/K，不能从总体平均H/P除以平均K倒推。精确数值见 `results/reference_summary.json`。

## 运行

使用 Python 3.11 或更高版本。建议在新建虚拟环境中安装依赖：

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux 使用 source .venv/bin/activate
python -m pip install -r requirements.txt
python run_main.py
```

程序只依赖 NumPy 和 pandas，在本地CPU运行，不需要原项目、原始Excel、患者级资料、GPU、Gurobi或任何在线服务。默认结果写入 `outputs/reproduced/`。为避免覆盖，输出目录必须尚不存在；再次运行请指定新目录：

```bash
python run_main.py --output outputs/reproduced_2
```

运行会重新构造联合情景、计算内部参考、筛选并选择方案，然后计算实际目标日H/P/J。随后逐例核对所有动作、成功状态及主要预测/实际指标；核查病区之和、来源接收量和信息可得性。`verification.json` 中 `passed=true` 表示这些检查通过。生成目录不属于发布文件，已由 `.gitignore` 忽略。

## 数据处理与适用范围

公开数据由冻结的整理后日表按字段白名单导出，保留真实计数、分析床位和缺失情况；没有生成模拟数据或为改善结果删除日期。成人与患儿共同计入主口径。

病区名称替换为 W1—W4，两个需求来源记为 S1、S2。实际日期替换为连续相对日序，原名称/日期映射均不随包提供。患者记录、原始Excel、姓名、住院号、源工作表名称及本机路径均不在本包中。日级汇总仍可能带有可联系到外部背景的信息，不宣称具有形式化匿名性保证。见字段字典。

该包复现的是**已冻结参数下的主实验**，不包含重新训练历史模型或重新选择参数的实验。护理参照和内部参考系数作为冻结输入提供，其开发期来源在 METHOD.md 说明。原来跨方法共同可用的日期筛选标记予以保留，不能解释为“所有有完整日表的日期”。

本包不包含消融、其他方法比较、护理参照敏感性、事后可行上限枚举、论文复现、扩展研究或教学模拟数据。J-CAP筛选所必需的内部完全共享参考保留在主代码中，附来源说明；它不是一个另外运行并报告的文献baseline。

评价时段曾用于多轮研究探索，结果应称为探索性回放，不能当成新的独立验证。H为规划中的护理人力参照超额患者当量，不是护理工时、临床安全阈值或患者伤害。预测筛选约束不保证实际H/P/成功率不劣于内部参考。
